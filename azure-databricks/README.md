# Azure Databricks and PySpark

## Overview

Azure Databricks is used for data processing and transformation in this project. PySpark is used to perform data engineering operations on datasets stored in Azure Data Lake Storage Gen2.

## Implementation

The following activities were performed:

- Connected Azure Databricks with Azure Data Lake Storage Gen2.
- Accessed raw datasets from the Bronze layer.
- Used PySpark for data cleaning and transformation.
- Processed datasets and organized the output into the Silver and Gold layers.
- Prepared structured data for downstream analytics.

## Key Concepts Learned

- Azure Databricks workspace and compute
- Apache Spark and PySpark
- Reading and writing data
- Data cleaning and transformation
- DataFrame operations
- Medallion Architecture integration

## Outcome

Implemented data processing and transformation workflows using Azure Databricks and PySpark to prepare datasets for analytical use.
